# BlueFairy Layered Navigation for Hyvä: Features

- **The whole navigation on Hyvä.** Multi-select filters, price slider, swatches, "Show more", filter addresses and no-reload updates, as on Luma.
- **No RequireJS, no Knockout, no jQuery.** One small framework-free script.
- **Works with the strict content security policy.** No inline event handlers; the one inline script is registered with Hyvä.
- **No Tailwind rebuild.** A small stylesheet of its own, loaded on category and search pages only.
- **Themeable.** Colours are CSS custom properties.
- **Hyvä store views only.** Luma store views of the same installation are untouched.
- **Free.** MIT licence.
