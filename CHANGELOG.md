## 1.0.0 — 2026-11-10

### Added

- Hyvä storefront for BlueFairy Layered Navigation: start-up without RequireJS, registered with Hyvä's content security policy.
- A stylesheet for the navigation, loaded on category and search result pages of Hyvä store views, with colours as CSS custom properties.
- Under a strict content security policy, a product list that brings scripts the page is not running is loaded as a page instead of updated in place.
